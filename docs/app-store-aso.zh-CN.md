# App 市场搜索排名优化方案

本文整理 Unravel 上架成功后的 App Store / Google Play 搜索排名优化方案。目标是通过 ASO、商店页转化、评分评论、留存数据和版本迭代，持续提升搜索曝光、下载转化和自然流量。

## 1. 核心目标

上架后的搜索排名不是只由关键词决定，而是由“相关性 + 转化率 + 评分评论 + 留存活跃 + 下载增长 + 应用质量”共同影响。

优化目标分为四层：

1. 提高目标关键词下的搜索曝光。
2. 提高商店页点击率和下载转化率。
3. 提高评分、评论质量和用户信任度。
4. 提高下载后的留存、活跃和稳定性指标。

## 2. Phase 1：关键词与竞品调研

先确定目标用户会搜索什么，再决定标题、副标题、关键词和截图文案。不要只依赖产品名 `Unravel`，需要补充品类词和意图词。

建议建立关键词表：

| 关键词 | 搜索意图 | 竞争度 | 相关性 | 优先级 |
| --- | --- | --- | --- | --- |
| gacha simulator | 想体验抽卡模拟 | 中 | 高 | 高 |
| card collection | 想收集卡牌 | 高 | 中 | 中 |
| anime card game | 想找二次元卡牌 | 高 | 中 | 中 |
| wish simulator | 想找抽卡模拟器 | 中 | 高 | 高 |

调研时重点观察：

- 竞品标题、副标题和短描述如何表达核心玩法。
- 竞品前 3 张截图展示什么卖点。
- 用户评论里反复出现的正向关键词。
- 差评集中反馈的问题，例如加载慢、内容少、广告重、抽卡反馈弱。
- 高排名竞品的更新频率和版本说明写法。

## 3. Phase 2：商店素材优化

商店素材的首要目标是提升“搜索结果点击率”和“详情页下载转化率”。标题、图标、截图和首屏文案要让用户快速判断这是不是他们想找的应用。

建议素材结构：

| 素材 | 优化方向 |
| --- | --- |
| App 名称 | 保持 `Unravel`，避免堆砌关键词 |
| 副标题 | 补充品类和核心玩法，例如 `Card Collection & Gacha` |
| 简短描述 | 突出抽卡模拟、图鉴收集、轻量体验 |
| 图标 | 小尺寸下可识别，避免细节过多 |
| 截图 | 前 3 张展示核心玩法，不放空泛宣传语 |
| 视频预览 | 用 15-30 秒展示启动、抽卡、收藏闭环 |

截图顺序建议：

1. 抽卡动画或抽卡结果页。
2. 卡池选择、单抽和十连入口。
3. 图鉴收藏和稀有度筛选。
4. 个人进度、徽章或成就。
5. 主题视觉、活动页或特色卡片展示。

## 4. Phase 3：评分评论策略

评分评论会影响用户信任和搜索排名。评分引导要放在用户完成正反馈行为之后，不要在首次启动时强弹。

推荐触发时机：

- 首次抽到 SSR 后。
- 完成一次十连后。
- 收藏数量达到阶段目标后。
- 连续使用 2-3 天后。

建议流程：

1. 先展示应用内反馈入口，判断用户是否满意。
2. 满意用户再引导前往商店评分。
3. 不满意用户进入反馈表单或客服渠道。
4. 每次版本更新后复盘差评关键词，优先修复高频问题。

禁止买评分、刷评论或诱导虚假评价，这类行为可能导致搜索降权、审核风险或下架。

## 5. Phase 4：留存与数据优化

市场排名不仅看商店页表现，也会看用户下载后的行为。下载后快速卸载、崩溃率高、留存低，都会影响自然推荐和搜索表现。

建议埋点指标：

| 指标 | 目的 |
| --- | --- |
| 商店页曝光到下载转化率 | 判断素材吸引力 |
| 首次启动成功率 | 排查崩溃、白屏、卡死 |
| 首次抽卡完成率 | 判断新手路径是否顺畅 |
| 次日留存 D1 | 判断核心体验吸引力 |
| 7 日留存 D7 | 判断长期回访价值 |
| 卸载率 | 判断体验或预期落差 |
| 评分弹窗触发转化 | 判断评论策略是否有效 |

产品侧优先优化：

- 启动速度和首屏加载稳定性。
- 首次进入尽快看到核心玩法。
- 新手流程保持轻量，不要阻断抽卡体验。
- 第一次抽卡给出明确反馈和情绪价值。
- 用图鉴、进度、卡池更新或成就系统提供回访理由。

## 6. Phase 5：持续更新节奏

上架后的前 4 周是验证关键词、素材、留存和评论的关键窗口。版本更新要围绕真实数据和用户反馈，不要为了更新而更新。

建议节奏：

| 阶段 | 动作 |
| --- | --- |
| 上架后第 1 周 | 每天检查崩溃、评论、转化和下载趋势 |
| 第 2-4 周 | 每周发布一次小优化或素材调整 |
| 稳定后 | 每 2-4 周发布一个版本 |
| 节点活动 | 配合节假日、主题卡池或限时收藏更新 |

版本说明要写用户能理解的变化：

```text
- 新增限定卡池
- 优化十连抽动画表现
- 改进图鉴筛选体验
- 修复部分设备启动异常
```

## 7. 风险与注意事项

- 不要关键词堆砌，可能降低转化，也可能触发审核问题。
- 如果 `Unravel` 搜索竞争较高，需要用副标题、关键词字段和截图文案补足品类词。
- 正式上架前建议把 bundle id 从示例域名改成自有域名，例如 `com.yourcompany.unravel`。
- 如果应用仍是 Demo 形态，需要补充内容深度、隐私政策、概率说明和必要的用户协议。
- 涉及抽卡、概率、虚拟资源时，要特别关注平台审核规则和当地合规要求。

## 8. 优先级清单

1. 先完成竞品关键词表和商店页素材方案。
2. 再接入基础埋点、崩溃监控和评分引导。
3. 上架后用 2-4 周做标题、副标题、截图和描述的 A/B 测试。
4. 根据搜索词、转化率、留存和差评内容持续调整产品体验。
